# 🏎️ F1 Intelligence 2026

A real-time Formula 1 analytics and prediction platform for the 2026 season based on 27,326 data entries.

## Features
- 📊 Live driver & constructor standings
- 🔮 Qualifying & race predictions powered by XGBoost ML model
- 🧠 AI Race Engineer assistant
- 📈 Historical performance analysis per driver per circuit (2018–2026)
- 🗓️ Full 2026 race calendar with results

## Data Sources
- Historical race data (2018–2026)
- Circuit-specific driver performance metrics
- Safety car, VSC & red flag probabilities
- Pit stop averages per circuit

## Tech Stack
- Pure HTML/CSS/JavaScript (no framework)
- XGBoost-inspired prediction model (client-side)
- Anthropic Claude API (AI Race Engineer)
